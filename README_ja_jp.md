# CoreSystem

CoreSystem は、ローカル AI と学習ループを統合するプロジェクトです。コマンド駆動の自動化、ローカル推論、外部ゲートウェイ連携、ペルソナベースの記憶、メディア管理、モデル学習をまとめて扱います。

## ディレクトリ概要

- `01_bin/`: コマンド駆動型のシステム制御、CLI ツール、自動化フックを含む実行ディレクトリ。
- `02_local_ai/`: ローカル小型モデル、推論ランタイム、スクリプトを含む AI ディレクトリ。
- `03_gateway_ai/`: ゲートウェイ設定、プロキシ、クライアントアクセスの外部 AI インターフェース。
- `04_persona_godview/`: 身元、役割視点、共有メモリを持つ個人視点のディレクトリ。
- `05_media_vault/`: 原本メディア、処理済み結果、共有リンクを保管するメディア倉庫。
- `06_ai_training_lab/`: データソース、パイプライン、データセット、学習ジョブを管理する AI 実験室。

## 主要目標

- 完全制御: `01_bin/` でローカルコマンドを実行し、デバイスとワークフローを自動化する。
- ローカル AI: `02_local_ai/` で軽量のオンデバイスモデルを実行し、プライバシーとオフライン能力を確保する。
- 外部インターフェース: `03_gateway_ai/` を通じて外部 LLM やクラウドサービスへ接続する。
- 多役割共有: `04_persona_godview/` でペルソナと神の視点を管理し、意思決定と知識共有を統合する。
- メディア管理: `05_media_vault/` でメディア資産を集中管理し、構造化処理と共有を行う。
- 学習ループ: `06_ai_training_lab/` で各ディレクトリのデータを収集して、ローカルモデルを継続的に改善する。
