# 04_persona_godview/02_personas

このディレクトリは、個人の役割視点を定義・管理するための領域で、複数の独立したペルソナ設定、記憶、能力拡張をサポートします。

## 典型的な役割

- `developer/`: コーディングと技術アーキテクチャに特化した役割視点。
- `life_manager/`: 日常生活、時間管理、個人業務に特化した役割視点。
- `strategist/`: 判断分析、振り返り、長期計画に特化した役割視点。

## 目的

異なる役割が同じシステム内に並立し、問題領域ごとに文脈を切り替えながら必要な情報を共有できるようにします。
