# 02_local_ai

`02_local_ai/` is the local small-model AI and runtime directory focused on edge-side offline capabilities and privacy-aware processing.

## Structure

- `01_models/`: local model weights such as GGUF or AWQ lightweight model files.
- `02_runtimes/`: local inference engines and runtime environments such as llama.cpp, Ollama, and Executorch.
- `03_scripts/`: scripts for loading, benchmarking, and exposing local models through APIs.

## Goal

Build a lightweight, locally runnable AI platform for daily offline inference, automation agents, and privacy-sensitive text/data processing.
