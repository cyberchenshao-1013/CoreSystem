# CoreSystem

本仓库实现了一个通用的本地AI与训练闭环架构，目标是构建一个可命令行控制、支持本地小模型、对外接口、人格上帝视角、多媒体管理和训练生产的根目录。

## 目录概览

- `01_bin/`：命令行为主的可执行工具目录，承载系统控制、CLI 工具和自动化钩子。
- `02_local_ai/`：本地小AI模型目录，包含模型、推理运行时和脚本。
- `03_gateway_ai/`：对外AI接口目录，负责网关代理、配置管理和客户端调用。
- `04_persona_godview/`：个人视角与多角色共享目录，支持核心身份、角色视角与共享记忆。
- `05_media_vault/`：多媒体仓库目录，管理原始内容、处理结果和共享链接。
- `06_ai_training_lab/`：AI训练实验室目录，构建从数据源到训练作业的闭环。

## 核心目标

- 完全掌控：通过 `01_bin/` 运行本地命令与自动化工具，实现对设备与流程的统一控制。
- 本地AI：在 `02_local_ai/` 中运行轻量级端侧模型，确保隐私与离线能力。
- 对外接口：在 `03_gateway_ai/` 中连接外部大模型与云服务，扩展本地能力。
- 多角色共享：在 `04_persona_godview/` 中管理多角色视角与个人上帝视角，实现统一决策与知识共享。
- 媒体管理：在 `05_media_vault/` 中集中管理多媒体资产，并支持结构化处理与共享。
- 训练闭环：通过 `06_ai_training_lab/` 自动从各目录采集数据、清洗并训练本地模型。
