# 05_media_vault

`05_media_vault/` is the personal media collection and shared-access directory, centralizing raw content, processed outputs, and shared links.

## Structure

- `01_raw_media/`: raw images, videos, audio, and documents.
- `02_processed/`: AI-processed structured data, labels, transcriptions, and summaries.
- `03_shared_links/`: read-only mounted locations and link directories for LAN or multi-role sharing.

## Goal

Build a secure, searchable media asset vault that supports downstream AI processing and shared usage.
