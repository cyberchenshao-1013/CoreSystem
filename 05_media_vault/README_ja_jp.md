# 05_media_vault

`05_media_vault/` は、原本メディア、処理結果、共有リンクを一元管理し、ローカルでのメディア運用を支えるディレクトリです。

## 構造

- `01_raw_media/`: 元の画像、動画、音声、ドキュメントなどの原本ファイル。
- `02_processed/`: AI 処理後の構造化データ、ラベル、転写、要約結果。
- `03_shared_links/`: LAN やマルチロール共有に使う読み取り専用のマウント先やリンクディレクトリ。

## 目的

安全で検索しやすいメディア資産の保管庫を構築し、後続の AI 処理や共有利用を可能にします。
