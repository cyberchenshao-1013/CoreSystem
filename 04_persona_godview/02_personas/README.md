# 04_persona_godview/02_personas

This directory defines and manages personal role perspectives, supporting multiple independent persona configurations, memories, and capability extensions.

## Typical Roles

- `developer/`: role perspective focused on coding and technical architecture.
- `life_manager/`: role perspective focused on daily life, time management, and personal affairs.
- `strategist/`: role perspective focused on decision analysis, review, and long-term planning.

## Goal

Allow different roles to coexist in the same system so context can be switched across problem domains while sharing necessary information.
