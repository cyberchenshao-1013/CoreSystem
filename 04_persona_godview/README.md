# 04_persona_godview

`04_persona_godview/` is the personal perspective and multi-role sharing directory, including god-view configuration, persona perspectives, and shared memory foundations.

## Structure

- `01_core_identify/`: core identity definitions, values, long-term goals, and personal preference configuration.
- `02_personas/`: multi-role personal views for different missions and workflows.
- `03_shared_memory/`: shared knowledge bases, histories, and contextual data across roles.

## Goal

Construct a unified knowledge and decision-making system from a personal perspective, enabling multiple persona views to collaborate while reducing information silos.
