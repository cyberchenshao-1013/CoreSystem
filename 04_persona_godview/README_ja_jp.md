# 04_persona_godview

`04_persona_godview/` は、人格設定、役割視点、共有メモリを含む個人視点と多役割共有のディレクトリです。

## 構造

- `01_core_identify/`: 中核的な自己定義、価値観、長期目標、個人設定。
- `02_personas/`: 異なるミッションやワークフローに対応する複数のペルソナ視点。
- `03_shared_memory/`: 役割間で共有される知識ベース、履歴、コンテキストデータ。

## 目的

個人視点から統合された知識と意思決定システムを構築し、複数の役割視点が协働しながら情報分断を減らします。
