# 01_bin

`01_bin/` は、システムレベルのコマンドと実行スクリプトを格納するディレクトリで、主にコマンドライン駆動の自動化と制御に使用します。

## 構造

- `01_sys_control/`: 電源、スリープ、ロック、スクリーンショット、ネットワークプロキシ切り替えなどの低レベル制御スクリプト。
- `02_cli_tools/`: ファイル同期、クロスデバイスクリップボード、クイック操作、システム管理向けのカスタム CLI ツール。
- `03_hooks/`: 実行前後の検証、自動化チェック、セキュリティポリシーを含むシステムフック。

## 目的

ローカルのシステム操作と自動化ワークフローを、コマンドラインから統一的に呼び出し、組み合わせ、拡張できる実行基盤を提供します。
